# 🚀 초보자용 프로젝트 실행 가이드 (중고생용)

안녕! 이 프로젝트는 병원 시스템을 아주 작게 쪼개서(MSA) 만들어진 프로그램이야. 복잡해 보이지만, 아래 단계를 차근차근 따라 하면 누구나 실행할 수 있어!

---

## 1단계: 준비물 (이것만 있으면 돼!)
1. **Node.js**: 자바스크립트를 실행해 주는 도구야.
2. **웹 브라우저**: 크롬(Chrome)이나 엣지(Edge)면 충분해.

## 2단계: 가장 쉬운 방법 (Mock 서버 실행)
실제 병원 시스템을 전부 돌리려면 컴퓨터 사양이 좋아야 하지만, 우리는 **"가짜 서버(Mock Server)"**를 써서 아주 가볍게 돌려볼 거야.

1. 이 프로젝트 폴더에서 터미널(또는 명령 프롬프트)을 열어.
2. 아래 명령어를 입력해:
   ```bash
   node mock-server.js
   ```
3. 화면에 `Medical MSA Mock Server running at http://localhost:8080`이라고 나오면 성공!

## 3단계: 화면 확인하기
1. 인터넷 주소창에 `http://localhost:8080`을 입력해.
2. **관리자 화면**이 나올 거야. 여기서 환자를 등록하고 예약을 잡아봐!
3. **환자 포털** 버튼을 누르면 환자가 직접 자기 내역을 확인하는 화면으로 갈 수 있어.

---

## 💡 실행 팁!
- **연동이 안 될 때**: 웹 페이지를 새로고침(F5) 해봐.
- **끄고 싶을 때**: 터미널 창에서 `Ctrl + C`를 누르면 꺼져.
- **더 공부하고 싶다면**: `DOCKER_GUIDE.md`를 읽고 진짜 데이터베이스(Postgres)를 연결하는 법에 도전해 봐!

## 🌟 무엇을 확인할 수 있나요?
- 내가 등록한 환자가 **환자 포털**에서 잘 보이는지?
- 처방전을 발행하면 **처방 내역**에 바로 나타나는지? (이번에 수정한 부분이야!)
- 예약이 확정되면 **실시간 알림**이 오는지?

이제 나만의 미니 병원 시스템을 마음껏 테스트해 봐! 🐕
